## Cum uploadezi pe GitHub

1. Intra pe GitHub la repository-ul tau
2. Click **Add file > Upload files**
3. Trage toate fisierele si folderul `images` deodata
4. Click **Commit changes**
5. Gata! Asteapta 2-3 minute si site-ul e live
